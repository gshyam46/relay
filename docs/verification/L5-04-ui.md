Date: 2026-09-13. Contract: [L5-04 data lifecycle](../L5-04_DATA_LIFECYCLE.md).

## Implemented owner flow

Settings / Workspace data displays the scoped inventory, limits, erasure holds and export omissions. Export downloads the server's customer-data JSON manifest and records. Explicit erasure first reads a current plan, then requires the exact `ERASE WORKSPACE CUSTOMER DATA` phrase and current password. The account, security records, minimum exact-contact suppression and completed erasure receipts remain; channel setup resets and dispatch pauses. The UI distinguishes active-database erasure from backups, logs, exported files, storage remnants and provider copies.

An uncertain command retains its exact request key, plan and confirmation. The pending command never stores the password; the page clears the password when a POST settles. GET recovery requires no password. Explicit POST retry requires re-entry and reuses the original command. A later wrong-password rejection cannot make an earlier unknown outcome look definitively rejected. Late results are accepted only for the matching pending key. Confirmed erasure removes non-authentication query caches. Completed receipts survive reload, and history includes a read-only lookup by a saved request reference.

The approved follow-on also updates manual capture in `client/src/pages/leads.tsx`: contact is optional, supplied fields remain bounded/validated, and a real modal supports keyboard focus and narrow screens. A network/5xx create failure holds the draft against duplicate resubmission and offers explicit directory inspection. Manual capture has no durable request identity: inspection does not prove which command created a similar record, and closing the draft does not cancel accepted work. No automatic recovery or deduplication is claimed.

Owned source: `client/src/pages/leads.tsx`, `client/src/components/workspace-data.tsx`, `scripts/helpers/workspaceDataFixture.js`, and `scripts/verify-workspace-data-ui.js`. Root owns Settings integration, API/service wiring and the tracked launcher.
