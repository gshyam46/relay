## Contracts Changed

- Classification JSON adds generation, exact UTF-16 evidence, review_required and optional candidate under reply policy/prompt v1. Existing event categories, contact restrictions and follow-up states remain authoritative.
- Channel messages and lead timeline expose the same bounded interpretation. Timeline original_text is nullable; application summary is never presented as missing customer text. Known version/mode/reason/category consistency and exact nonempty evidence are required before displaying method authority; malformed history stays unavailable/review while preserving its stored category.
- Model transport caps requests at 256 KiB, JSON responses at 64 KiB, deadlines at 15 seconds, text messages at 32 and requested output tokens at 4096. Redirects, automatic retries, tools, refusal, nontext/truncated/malformed completions are rejected with fixed safe errors.
- Empty model selection becomes NO_SUPPORTED_SELECTION fallback. Synthesis pipeline l3.02-extractive-synthesis-v3 prevents old derived reuse under existing currentness rules without rewriting historical reviewed copy.

Exact quoted support proves attribution, not semantic correctness or source truth. Possible-model opt-outs can impose conservative restrictions pending review; this slice does not implement resubscription.

Customer/native-language labels, real configured-model quality/latency/cost, PostgreSQL/provider operation, mobile/accessibility and pilot usefulness remain open. Historical raw payload retention and full inbox pagination/assignment/resolution are unchanged. A source reference can be unavailable when historical support is missing.
