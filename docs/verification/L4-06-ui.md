Root owns final static metadata, operational purge and publication requirements.

Desktop collapse preference remains independent. Expanded navigation includes the full product identity, collapsed links have accessible names, and page-header actions wrap.

## Browser cases and failure distinctions

The 15 actual React checks cover public information during API unavailability; real privacy links/keyboard/360px information layout; empty persisted setup; keyboard-guided real profile save; independently configured fit criteria and a selected enquiry; actual analysis and its currentness destination; exact message approval followed by edit invalidation; actual reminder/current outcome metadata and workflow link; GET-only refresh; recoverable unavailable GET; a genuinely invalid persisted profile becoming unavailable while other steps remain visible; drawer keyboard focus/Escape/navigation/resize and desktop preference; actual 390px page/guide width plus access to the last step; a separate owner's empty workspace; and stable assets with no browser errors, model calls or unexpected browser mutations.

The unavailable setup response is a browser-intercepted 503. The invalid profile, profile/criteria records, analysis, composer review/edit, reminder and outcome use actual local persistence/services. Fixture writes are distinct from browser behavior: only the explicit profile save is a browser-issued mutation during the guide flow. The public information API failure is intercepted; the page itself makes no API request. The safe fixtures start no broad outbound worker and block browser requests outside their own loopback origin.

Two concrete UI defects were fixed without weakening the assertions:

1. The historical fixed 240px sidebar left about 126px for content at a 390px viewport. The shared mobile drawer and wrapping header restore usable width.
2. Chromium's native dialog boundary allowed Shift+Tab to leave the modal's first control. Explicit boundary wrapping now keeps keyboard traversal inside the drawer; native modal isolation remains.

Early verifier-only mismatches were corrected to the existing profile-save label, outcome heading and composer HTTP 200 acceptance. The original behavior checks remained intact.
