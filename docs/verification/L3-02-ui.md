## Reproduction and isolation

The tracked [fixture helper](../../scripts/helpers/intelligenceTrustFixture.js) constructs a fresh SQLite :memory: application bound only to an owned 127.0.0.1 port. It refuses non-test mode, persistent databases, inherited provider configuration, enabled workers and mismatched public origin. Application synthesis/reply services use injected local adapters; no production fixture route is installed. Normal application APIs persist the synthetic records and classifications. The verifier checks the isolated E2E handshake, blocks browser requests outside its origin and closes its browser/server/database in finally.

Run the following from the repository root in PowerShell, with the already installed Playwright module at the explicit path shown. No package installation or environment-file load is involved.

```powershell
@'
import net from "node:net";
import { spawn } from "node:child_process";
import { e2eEnvironment, safeTestEnvironment } from "./scripts/helpers/testSafety.js";
const probe = net.createServer();
await new Promise((resolve, reject) => { probe.once("error", reject); probe.listen(0, "127.0.0.1", resolve); });
const port = probe.address().port;
await new Promise(resolve => probe.close(resolve));
const env = e2eEnvironment({ ...safeTestEnvironment(), E2E_PORT: String(port) });
env.PUBLIC_APP_ORIGIN = "http://127.0.0.1:" + port;
const child = spawn(process.execPath, ["scripts/verify-intelligence-trust-ui.js", "--playwright-module", "C:/Users/ghg/anaconda3/Lib/site-packages/playwright/driver/package/index.mjs"], { env, stdio: "inherit", windowsHide: true });
process.exitCode = await new Promise((resolve, reject) => { child.once("error", reject); child.once("exit", code => resolve(code ?? 1)); });
'@ | node --input-type=module
```
