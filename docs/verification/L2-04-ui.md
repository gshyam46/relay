## Implemented owner journey

The Leads directory now requests bounded server pages and offers current, archived or all records, text search, supported source choices and recorded-status filtering. Archived is visibly separate from opt-out/suppression. Explicit export selection survives page/filter changes and detail navigation within the current browser session and workspace. The interface shows selected and not-on-this-page counts. Selecting a page adds only its displayed IDs, supports at most 1000 IDs and never turns an empty selection into all records. Export has no archive side effect; archive is available only on a named single lead.

Lead data opens current saved contact values, normalized contacts, revision and per-field origin. The owner can correct name, email, phone and company with explicit international/India/US phone interpretation. Preview presents saved/proposed normalized values, matching enquiries, contact-policy reasons and channels, incomplete/truncated review notices, and affected work. An explicit reason and reviewed confirmation are required before saving. Correction does not merge enquiries or clear contact restrictions. It blocks queued actions, stops workflows and cancels automatic follow-ups while retaining existing human tasks. Original import facts and source history remain separate.

A stale revision or comparison preserves the draft and requires an explicit latest-data replacement and another preview. An uncertain save reads current data/history before retry. If a newer recorded revision exists, the interface asks the operator to inspect it, without assuming that another owner's change is the requested result. If no newer revision exists, only the exact retained command can be retried explicitly. If current data cannot be read, retry remains unavailable. If an explicit retry gets a definitive stale-review response, uncertain-command mode ends, the draft remains, and the operator can load current data and obtain a fresh preview. Accepted replay results are followed by a latest-data read so the UI does not treat an older recorded response as the latest revision.

Archive and restore use a separate native dialog naming the single record, explaining effects and requiring a reason. Its reviewed revision is frozen when opened; a background revision change disables confirmation. A rejected stale archive preserves its reason for explicit review after loading the latest data. Archive stops open workflows, blocks queued actions and cancels all open follow-ups, including human tasks. Existing dispatched or uncertain work may still require recovery review. Archived details, enquiry facts, source links, history and selected export remain readable. Contact/context editing, analysis, messaging, scheduling and action review/execution controls are unavailable on archived detail; delivery recovery remains inspectable. Restore retains recorded status and restrictions and starts no previous work. Backend guards remain authoritative, including stale open pages.

Change history displays before/after values, per-field source, kind, reason, actor/time and work-effect counts, with explicit older/newer paging. The CSV download uses the server attachment response and exact selected IDs, validates content type/count/size, and retains selection after success or failure. Display fields have visible text: protection where appropriate; JSON columns preserve exact contact/enquiry values and money. This operational export is not a backup.

~~~text

Direct Node entry points avoid the checkout's PowerShell/npm launcher limitations without altering execution policy or installing dependencies.

After launching an owned disposable E2E server and setting VERIFY_BASE_URL to its verified loopback origin:

~~~text
node scripts/verify-lead-data-ui.js --playwright-module <absolute-local-playwright-package/index.mjs>
~~~

The verifier checks the isolated-E2E handshake before creating fixtures, uses safeTestEnvironment, and blocks browser requests outside the owned origin. It uses the existing Playwright core 1.55.0-beta-1756314050000 package and cached Chromium 140.0.7339.16. Each run owns an ephemeral loopback server and in-memory SQLite database; the harness closes server and browser. No customer data, provider credential, external provider or package installation is used. Fixture APIs prepare imports, restrictions, matching contacts and concurrent owner changes; actual production React controls perform the reviewed correction, recovery, archive/restore, history navigation, filters, selection and CSV download.

## Remaining acceptance and limits

Required operator QA remains open: correct a real mistaken contact without confusing another enquiry; understand each retained restriction/channel and affected human versus automatic work; resolve a stale or uncertain save; archive and restore the intended single record; find older history; and download only the selected records without developer assistance. Confirm keyboard-only dialogs, focus through errors, screen-reader announcements, zoom, mobile and long multilingual values. Automated desktop execution and engineer inspection do not certify these outcomes.

Open the exported file in supported Excel and LibreOffice versions and confirm formula protection, visible text: markers, exact budgets, Unicode and quoted multiline values. JSON columns preserve the canonical data; spreadsheet viewing is not a universal round-trip contract. Existing source-backed CSV formula/precision unit coverage is maintained by the integrating owner.

Selection is in-memory and workspace-scoped, not durable across a browser reload. History and candidate display are bounded and disclose incomplete results. There is no bulk archive, identity merge, contact-alias creation, full source pagination or business-wide privacy deletion workflow in this slice. The broader application still requires mobile/navigation/accessibility and bundle-size work; an explicit local Playwright path is not yet a dependency-locked portable CI browser setup. Real PostgreSQL concurrency/upgrade/restore, customer/operator acceptance and provider evidence remain external gates.
