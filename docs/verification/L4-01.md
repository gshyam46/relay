Normal runtime allows Sandbox and human tasks. The explicit legacy adapter profile requires test mode plus test controls and excludes the isolated browser harness.

Older saved envelopes that omitted an explicit configured return address require a new review; neutral absent-address envelopes remain compatible without a global policy-version bump. A return mailbox alone is not exact enquiry/thread correlation.
