## Completed

Source corrections remain separate. Typed workspace/lead/artifact references, immutable private input capture and review tokens preserve the result actually reviewed.

Intelligence now supports explicitly nominated reply selection, immutable named dataset versions, permanent enquiry/text DEV/HOLDOUT assignment, bounded local replay and aggregate result history. Protected groups permit one evaluation across versions; the original same-candidate request returns its saved result. Relabeling/withdrawal makes old evidence historical without releasing reservations. Feedback and replay cannot change canonical replies, stop restrictions, tasks, approvals or outbound actions.

The offline engineering evaluator now checks a pinned pre-change baseline, fixed corpus, actual source identity, class recall/abstention floors and existing grounding/provider/composer safety. Both npm run ci and GitHub SQLite CI run the gate.
