## Known issues

No live provider, hosted account, customer dataset or deployment was used. The configured-model browser and accounting scenarios use injected synthetic responses. SQLite verification does not establish PostgreSQL concurrency, restricted roles, migration/restore or multi-process behavior. Current-day usage is visible; complete historical reporting and retention remain later work. A lost process can leave usage unknown; logical slot expiry does not prove remote cancellation, and a later bounded retry can incur another invocation.

The React bundle remains over the existing Vite advisory size. Full operator composer/inbox/outcomes, account/operations acceptance and the interactive landing page are still later scope. L3-03 remains [~] for required human/external gates.
