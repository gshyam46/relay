# Bundled product fonts

Unmodified WOFF2 Latin variable subsets of Manrope and Newsreader, downloaded from Google Fonts on 2026-09-14. Copyright and SIL Open Font License 1.1 are preserved in the adjacent OFL files. CSS uses font-display: swap and system fallbacks for unavailable glyphs. No third-party font request is made by the application.

Source stylesheet: https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=Newsreader:ital,opsz,wght@0,6..72,400..600;1,6..72,400..600&display=swap

Upstream families: https://github.com/google/fonts/tree/main/ofl/manrope and https://github.com/google/fonts/tree/main/ofl/newsreader.
